DielectricBIE.BatchResult — Type
BatchResult

Everything the post-eval phase needs from one solved batch: the raw truncated pair densities (global-grid indexed), the adapted interface, the layer densities Σ, and solve stats. Positions are NOT stored — they are recomputed from gidx + the template. Files are tied to the exact code version that wrote them — the version field guards the BatchResult layout only, not the serialized interface type; after changing interface/panel struct layouts, re-solve affected batches.

DielectricBIE.BatchedDielectricOperator — Type
BatchedDielectricOperator

Matrix-capable adjoint-double-layer + diagonal operator for the dielectric BIE. A single batched FMM (nd = K) serves an N x K block; the sparse near correction and the diagonal contrast term are applied as batched mat-mat / broadcasts.

DielectricBIE.BlockCorrection — Type
BlockCorrection(C, interface)

A near correction C (sparse, Nt × N: targets × interface nodes) stored as dense blocks, one per source panel: block k maps the nodal values of panel k (columns cols[k]) to the targets near it (rows[k], the rows with a nonzero in those columns). mul!(Y, B, X, α, β), B * x and B * X apply it to a vector or an N × K block with Julia threads; sparse(B) converts back. Dense blocks hold each (panel, near target) row in full, like the builders produce them, and need no index per entry.

DielectricOperator

DielectricBIE.EdgeGCQRule — Type
EdgeGCQRule

Weighted GCQ rule on [0,1] and the data to interpolate in its span:

  • x, w : nodes and weights acting on density values (∫₀¹ σ ≈ Σ wj σ(xj))
  • pw : weight power p_1 (σ = x^pw v)
  • segs, z0, wz : fine grid (segments with 14-point Gauss-Legendre on [-1,1])
  • P : (n_fine × n) matrix, σ node values -> fine-node values of v
  • pows : exponents of the integrated family

DielectricBIE.GCQPotential — Type
GCQPotential(; quad_tol = 1e-12, η_gcq = 2.0, gcq_far = :max, far = FMM3DFarField(1e-12))

Off-surface single-layer potential for TensorPanel (GCQ) interfaces, accurate near edges and corners: the node rule over all nodes by the far-field backend far (FMM3DFarField or SCTLFarField), plus, for every (panel, target) pair that tensor_isfar rejects at quad_tol, the product-integration row of tensor_near_row minus the node rule. The same quadrature as potential_tensor, which sums directly over all pairs; candidate pairs are found with a KD tree. gcq_far as for GCQNearQuad.

DielectricBIE.HCubaturePotential — Type
HCubaturePotential(tol; range_factor = 5.0)

laplace3d_pottrg_fmm3d_corrected_hcubature: panels near targets are refined, FMM3D evaluates the node rule, and targets within range_factor × (panel size) / n_quad of a panel's centre get an adaptive cubature (HCubature) correction. Targets near the edges or corners of panels can fall outside that range and get no correction (errors up to 1e-3 at distances 1e-4 from the surface were measured); see SCTLPotential.

DielectricBIE.NearFieldGeometry — Type
NearFieldGeometry{T}

Section 3 near/far geometry for one volume source. lo/hi are the corners of the padded near region B_pad (Eq. 3.9), center is the centre of B (which is also the centre of B_pad), l the side lengths of B (Eq. 3.7), h the characteristic spacing (Eq. 3.3), hn = c_pad * h (Eq. 3.10), L the truncation radius (Eq. 3.11), and dks the Fourier spacings (Eq. 3.16 at equality).

DielectricBIE.NearQuadrature — Type
NearQuadrature

Near-field quadrature of the dielectric operator: near_corrections(q, interface) returns the sparse N × N correction C = (accurate D^T) - (node-rule D^T), so that D^T_nodes + C is the corrected operator.

Built in:

  • UpsampledNearQuad: upsampling plus adaptive quadtrees for FlatPanel interfaces (the default there);
  • GCQNearQuad: the product-integration rules of the GCQ edge panels (TensorPanel interfaces, default);
  • SCTLNearQuad: SCTL's singular quadrature of QuadElemList (needs SCTLFarField and using SCTL);
  • SCTLNearCorrection: the same quadrature as a sparse correction, with any far field (using SCTL);
  • CorrectionMatrix (a precomputed C) and FunctionNearQuad (C = f(interface)).

A self-defined quadrature is a subtype with a near_corrections method:

struct MyQuad <: DielectricBIE.NearQuadrature
    tol::Float64
end
DielectricBIE.near_corrections(q::MyQuad, interface) = my_sparse_correction(interface, q.tol)

and is used as dielectric_operator(interface; near = MyQuad(1e-10)). Rows of C are targets, columns sources, in the node order of interface; entries follow laplace3d_DT's sign convention.

DielectricBIE.PrecomputedVolumeField — Type
PrecomputedVolumeField(vs; tol, kmax = nothing, c_pad = 5.0,
                       compute_pot = true, compute_grad = true,
                       cache_fft = false, cache_fft_pad = 1.25,
                       nthreads = min(TKM3D._ltkm_default_nthreads(), Sys.CPU_THREADS))

Target-independent precomputed spectral representation of the free-space Laplace potential (1/(4π r) convention) of a VolumeSource, for evaluation at many target batches without redoing per-call setup.

Construction (once): fix the evaluation box Bpad = source box B (Eq. 3.7) padded by `cpad * hwhereh = ||Arho||2(Eq. 3.3); the Fourier box follows Eqs. (3.11) and (3.16) vianearfieldgeometry. On that Fourier box, run the type-1 NUFFT of all source charges, apply the truncated Laplace kernelTKM3D.truncatedlaplace3dhat`, and (optionally) materialize the spectral gradient coefficients.

Evaluation (per batch): targets inside B use a type-2 NUFFT on the stored coefficients — near the source support this spectral evaluation is the only accurate option (point-charge summation has O(1%) quadrature error there); the FFT dimensions never change, so FFTW planning is reused. Targets outside B are well separated from the support and are evaluated with the FMM (lfmm3d at the field tolerance) — equivalent to the exact point sum within tolerance and asymptotically scalable in the batch size.

This removes the dominant cost of the RHS-adaptive mesh build, where the target-dependent Fourier box previously forced a fresh type-1 NUFFT + FFT plan at every refinement depth (~23 s per call on the production monolayer density; measured 16x build speedup with max rel deviation 1.4e-5 and no refinement-decision changes).

nthreads caps the internal FINUFFT transforms (both the construction-time type-1 and every evaluation's type-2), mirroring TKM3D.ltkm3dc's _ltkm_default_nthreads() default of 16 (override via env TKM3D_FINUFFT_NTHREADS): FINUFFT's default FFTW planner picks a pathological high-thread-count plan for these mode grids otherwise, and without this cap raising Julia's thread count degrades this path rather than speeding it up. The default additionally floors that 16 at Sys.CPU_THREADS so a small Slurm allocation (4-8 CPUs) doesn't oversubscribe — a strict improvement over ltkm3dc's unconditional default, not a divergence from it; Sys.CPU_THREADS reports the machine total and can over-report inside a cgroup-limited allocation, so TKM3D_FINUFFT_NTHREADS remains the precise control for batch jobs. The FMM branch (lfmm3d, out-of-box targets) is unaffected.

Memory: coeff holds prod(nmodes) complex doubles and grad_coeff three times that (≈1 GB and ≈3 GB at the production kmax); construction with compute_grad = true transiently holds both even if compute_pot = false. Use the compute_pot/compute_grad flags to store only what the consumer needs.

Cached-FFT mode (cache_fft = true, experimental): the standard in-box path re-runs the FFT of the full coefficient grid inside FINUFFT on EVERY type-2 exec (~0.4 s at production scale, independent of the target count). With cache_fft = true that FFT is done once at construction: the spectral coefficients are divided by the FINUFFT spreading-kernel Fourier factors (pre-deconvolution: the interpolation kernel's smoothing is corrected per mode up front), zero-padded onto a fine grid of cache_fft_pad * nmodes per axis, and inverse-FFT'd; per evaluation a native threaded ES-kernel interpolation reads the stored fine grid (cost ∝ targets, not modes — equivalent to FINUFFT's spreadinterponly type-2 exec, see _field_interponly_type2 for why it is not routed through finufft itself). The coefficient arrays are dropped and replaced by the fine grids (cache_fft_pad^3 ≈ 2x their size at the default 1.25). Accuracy relies on the spectrum having decayed to ~tol at kmax (guaranteed by the kmax estimate); the padding keeps the active modes away from the fine-grid Nyquist, where the upsampfac≈1 interpolation kernel loses accuracy — validated at ~5e-9 max relative deviation from the standard path (pad 1.25; pad 1.0 degrades the gradient to ~2e-6). Transient construction memory peaks at approximately 2× the final cached footprint, as the phi-corrected padded arrays, the bfft workspace, and (if compute_grad = true) all four grids coexist before the coefficient arrays are released (~16 GB at production scale).

Window-derivative mode (window_derivatives = true, opt-in). One real scalar fine grid serves the potential, the gradient and the Hessian.

  • Construction. The potential coefficients are divided by the Fourier factors of this mode's window, padded to window_sigma * nmodes per axis, and inverse-FFT'd once. Only the real part is kept, because the gathering weights are real. No derivative coefficient arrays or grids are built, and compute_pot/compute_grad are irrelevant: everything is served.
  • The window. The ES window, tapered to vanish smoothly at its support ends, exp(β(q - 1)) q^6 with q = sqrt(1 - z²). It is evaluated analytically together with its first two derivatives. Its width comes from window_tol (default tol * 1e-4) and window_sigma (default 1.5).
  • Evaluation. Per batch, with ξd = nf,d (Δkd (yd - cd)/2π + 1/2), td = ℓd - ξd and αd = nf,d Δkd/2π, one gathering gives ∂a φ = -C αa Σ g w'(ta) Π w, ∂aa φ = C αa² Σ g w''(ta) Π w and ∂ab φ = C αa αb Σ g w'(ta) w'(tb) Π w.
  • Accuracy. On smooth fields it matches the spectral route at equal tol. A fitted (FINUFFT-style piecewise-polynomial) window stalled the Hessian at 1e-10 to 1e-9, and the untapered ES fails at stencil transitions. Modes at the edge of the mode box are about 100× less accurate than low ones; kmax keeps the spectrum decayed there.

DielectricBIE.SCTLFarField — Type
SCTLFarField(; tol = 1e-10)

Far field by SCTL.jl's ParticleFMM (PVFMM, OpenMP, no MPI) at relative accuracy tol, keeping the octree across applications; with fewer than 40000 nodes it is an exact direct sum. PVFMM's gradients lose about 1.5 digits, so it runs with -log10(tol) + 2 digits (at most 15; PVFMM reaches about 1e-11 at best). Needs using SCTL (the DielectricBIESCTLExt extension). A block of K densities is K evaluations on the same tree.

DielectricBIE.SCTLNearCorrection — Type
SCTLNearCorrection(; tol = 1e-10)

SCTL's near correction as a sparse matrix: SCTL's near test (which targets are near which panel) and the singular / near-singular quadrature of its QuadElemList, minus the node rule (SCTL.jl's near_correction). For FlatPanel interfaces with n_quad in 4, 8, 12, 16, 20; unlike SCTLNearQuad it combines with any far field (FMM3DFarField too). Needs using SCTL.

DielectricBIE.SCTLNearQuad — Type
SCTLNearQuad(; tol = nothing)

SCTL's singular and near-singular quadrature (QuadElemList, BoundaryIntegralOp) for FlatPanel interfaces with n_quad in 4, 8, 12, 16, 20. It replaces the whole D^T_nodes + C by SCTL's operator, so it only combines with SCTLFarField; tol (default: the far-field tolerance) is the target accuracy (SCTL's operator gets tol / 100, as its FMM loses about two digits). Needs using SCTL.

source
DielectricBIE.SCTLPotential — Type
SCTLPotential(; tol = 1e-10)

SCTL's BoundaryIntegralOp for the Laplace single layer with the targets set: SCTL's near test (per-node Bernstein radius at tol), its near-singular rule (each target's closest point on the panel, dyadic refinement toward it) and PVFMM for the far field, the octree kept for all densities. Accurate to about tol at any distance from the surface, except for rounding: the near correction cancels the node rule's term of the nearest node, which for a target at distance d from a node costs about 1e-16 × (node spacing) / d (1e-9 at d = 5e-9). Any panels with polynomial densities (default_polynomial_panel: FlatPanels of any n_quad ≤ 20, Gauss-Legendre TensorPanels): each is a proxy SCTL element of order 4, 8, 12, 16 or 20 with the panel's geometry, the density interpolated to its nodes (exact). Needs using SCTL.

source
DielectricBIE.SCTLProxyNearQuad — Type
SCTLProxyNearQuad(; tol = 1e-12, fallback = GCQNearQuad(), polynomial = default_polynomial_panel, order = nothing)

SCTL's near quadrature for any panels whose density is a polynomial, through proxy elements, and fallback for the others. For each panel k with polynomial(panel) true:

  1. a proxy QuadElemList element of order order (default: the smallest of 4, 8, 12, 16, 20 at least the panels' node counts per direction) with the panel's geometry;
  2. SCTL's classification (near radius at tol) of all interface nodes against it;
  3. SCTL's near-singular rule for the near targets (off the panel's plane; Dᵀ vanishes in it), times the interpolation from the panel's nodes to the proxy's, which is exact for the panel's polynomial density;
  4. minus the node rule (dt_node_rule_block).

The other panels' columns come from near_corrections(fallback, interface, sources), so only those are computed. The defaults suit GCQ boxes: SCTL for the Gauss-Legendre panels (kind == :gl), the GCQ rules for the edge and corner panels, whose densities are singular. For FlatPanel interfaces every panel is polynomial and the fallback is unused. Combines with any far field. Needs using SCTL.

DielectricBIE._cutcell_correction — Method
_cutcell_correction(θ; p = 7) -> (δ, mlo)

Lattice levels at depths (m - 1 + θ) h into one side of a cut (m ∈ ℤ, m ≥ 1 on that side, θ ∈ [0, 1)). The rule integrating, on every cell and on the partial cell [0, θ h], the degree-p interpolant of the p + 1 levels centred on it (from both sides: the integrand is smooth across the cut, only the indicator jumps) has weights h ([m ≥ 1] + δ_m), with δ nonzero only for m in mlo:mlo+p. Returns δ on that range and mlo.

DielectricBIE.build_batches — Method
build_batches(pairs, centers, k_target) -> Vector{BatchSpec}

Partition the pairs into batches of approximately k_target pairs each, keeping the pairs of a batch spatially together.

Why K and not an anchor count: a batch's cost is (fixed work) + K x (per-pair work). The fixed part – one adaptive interface, one corrected LHS operator, one pottrg map over the evaluation targets – is paid once per batch regardless of K, so the batch COUNT drives it. Grouping by anchor count leaves K to the cutoff geometry (1 to 17 on the 198-orbital benchmark, mean 13.2), giving both more batches than necessary and a wide spread of per-batch cost, which unbalances a distributed run.

This is a graph-partitioning problem: with orbitals as vertices and pairs as edges, the pairs form a line graph whose vertices we want split into equal parts with few cut edges – two pairs sharing an orbital share source support, so keeping them together shrinks the batch envelope. For this geometry (a planar lattice; every orbital lies in one plane) recursive coordinate bisection on the pair midpoints realizes that objective directly and deterministically, with no graph library: pairs sharing an orbital have nearby midpoints, so geometric compactness and a small edge cut coincide. Parts come out within one pair of equal size.

Locality matters because the batch's interface is refined on the envelope of its sources: pairs that are far apart inflate the envelope and with it the interface, costing more in the solve than the batching saves.

Note the pairs of one anchor are NOT forced into the same batch – BatchSpec.anchors is metadata (the manifest TSV and equality) and nothing computational depends on that grouping. Freeing it is what lets the parts hit k_target closely.

DielectricBIE.dielectric_diagonal_scaling — Method
dielectric_diagonal_scaling(interface) -> Vector{Float64}

Diagonal right preconditioner P = G⁻¹ for the dielectric BIE operator A = G + Dᵀ + Cᵀ, where the contrast term is G = diag(t_P) with t_P = ½(ε_out+ε_in)/(ε_out−ε_in) per panel (this is −½γ_P in the paper's sign convention; the code carries the opposite sign in BOTH A and the RHS). Entry i is 1/t_{P(i)}, so A P = I + (Dᵀ+Cᵀ)P has its spectrum in one cluster at 1 rather than one cluster per distinct contrast.

Two properties worth knowing before using it:

  • |γ| > 1 for any pair of positive permittivities, so |1/t| < 2: the scaling is uniformly bounded and cannot amplify a row.
  • It is a no-op whenever the geometry has a single contrast, since then P is a scalar multiple of I and GMRES is invariant under scalar scaling of (A, F). Expect identical iteration counts on single-box problems.

It clusters the spectrum of a multi-material geometry; it does NOT help the |γ| → 1 (conductor) limit, where the eigenvalues of I + (Dᵀ+Cᵀ)P migrate toward 0.

DielectricBIE.edge_gcq_rule — Method
edge_gcq_rule(dpows; tol=1e-10, nsmooth=20, qmax=nothing)
edge_gcq_rule(eps_in, eps_out; angle=π/2, tol=1e-10, nsmooth=20, qmax=nothing)

Weighted GCQ rule for the density powers dpows (several contrasts may be combined with vcat). The family is {s^{p_k + n}} ∪ {s^n}, n = 0..nsmooth; with qmax given it is instead every such exponent up to qmax (n as large as needed), so dpows (the powers up to some gmax) choose the classes and qmax alone sets the size. Steps: fine grid for the weighted family, SVD of the weighted sample matrix (rank at tol), column-pivoted QR for the nodes, transposed Vandermonde solve for the weights.

Fine grid (grid):

  • :graded (default): dyadic segments [2^-k, 2^-k+1], k = 1..K, with 14-point Gauss-Legendre, and [0, 2^-K] with Gauss-Jacobi for the weight s^p1, so the weight is integrated exactly and p1 may approach -1 (checkerboard edges at high contrast). K is set so that the non-polynomial part of the family carries less than tol/10 on [0, 2^-K]: K ≈ log2(10/tol) / (1 + p1 + c), c the smallest non-integer exponent of v = σ/s^p1; a family needing K > 1000 (2^-K below the floating-point range) is refused.
  • :adaptive: adaptive Gauss-Kronrod on s^p1 · family (fails for p1 ≲ -0.95).

In both, the interpolation matrix P gives v at the 14-point Gauss-Legendre nodes of every fine segment (segs, z0).

DielectricBIE.eval_batch_core — Method
eval_batch_core(br, targets, store, dg, c) -> (source_pairs, V, rows, n_targets_used)

Evaluate Φ_a = u_inc[ρ_a] + u[σ_a] at the shared target set, then contract against every stored pair density. Returns the batch's source pairs, the n_pairs × K block, the global row indices it covers (all of them) and the target count. No file IO.

Every batch evaluates every row. A symmetry-restricted variant existed briefly – V[a,b] = V[b,a], so a batch need only own rows >= min of its own columns, with assemble_v mirroring the rest – and it was removed after measurement, because it was a large net loss:

  • it did cut the potential evaluation, 18.98 -> 11.19 G source-points (41%), about 2.4 node-hours on the 198-orbital campaign;
  • but a batch's rows then cover only a SUBSET of the shared target set, so the contraction needed a Dict remapping every global target index into the subset – built per batch (up to 7.3M entries) and probed once per target per row.

Measured on latticeconvl3eps2.4kb31 batch 1 (K = 31, full target set): the potential evaluation takes 235 s standalone, while the campaign's t_phi for that same batch was 1896 s. The 1661 s difference is this remapping and the serial loop around it – 87% of the batch, to save 2.4 node-hours across the campaign. The docstring of the removed function asserted the opposite ("the saving is NOT in the contractions – those are cheap dot products"); it was never measured.

Evaluating every row also makes the eval cost n_pairs × n_targets, hence independent of the batching, and it removes a second-order accuracy concern: with subsets, each batch refined its interface (_refine_interface_for_targets) against a DIFFERENT target set, so the quadrature a given entry received depended on which batch happened to own it.

assemble_v then mirrors nothing, and its max_rel_asym recovers its full meaning as an end-to-end check: every off-diagonal entry is computed twice, independently.

Continuous free-space Laplace TKM evaluator with arbitrary source points and preweighted quadrature masses. nthreads caps the internal FINUFFT transforms (default 16, or env TKM3D_FINUFFT_NTHREADS) to avoid the FFTW high-thread-count plan pathology; the FMM path is unaffected.
